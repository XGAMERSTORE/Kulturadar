# Nikinka WOW (Android)
Native Android Java app. Fetches current Google News RSS search results for 10 interest areas. Tap a result to verify the original source. Learns preferred categories locally from likes. No API key or external AI model is used in this first version; the relevance selection is rule-based, not generative AI. Requires internet.

## APK
Open GitHub Actions → Nikinka WOW Android APK → latest successful run → artifact Nikinka-WOW-APK. Debug APK is for testing. The GitHub Actions build has not been independently verified.

## Roadmap
Add secure AI backend for summarization and tailored questions, personalized ranking, WorkManager notifications, caching and privacy controls. Never embed paid AI API keys in the APK.
