# Bezpečnost / Security

Bezpečnost aplikace Kulturadar bereme vážně. Pokud objevíte bezpečnostní chybu, zranitelnost, problém s ochranou soukromí nebo podezřelé chování aplikace, neposílejte citlivé technické detaily do veřejného issue.

Kontakt pro bezpečnostní hlášení: **xghelpdesk@gmail.com**

Do zprávy prosím uveďte verzi aplikace, zařízení / verzi Androidu, stručný popis problému a kroky k reprodukci. Neposílejte hesla, přístupové tokeny ani jiné tajné údaje.

---

We take the security of Kulturadar seriously. If you discover a security vulnerability, privacy issue, or suspicious app behavior, please do not publish sensitive technical details in a public issue.

Security contact: **xghelpdesk@gmail.com**

Please include the app version, device / Android version, a short description, and reproduction steps. Do not send passwords, access tokens, or other secrets.
